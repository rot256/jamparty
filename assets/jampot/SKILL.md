# jampot

The `jampot` binary must be on your PATH.

Run `jampot agent` and follow the guide for your kind of agent:
`jampot agent claude`, `jampot agent codex`, `jampot agent t3` or
`jampot agent other`. The guidance lives in the binary, so it matches the
installed version.
