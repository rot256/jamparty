# nabe

The `nabe` binary must be on your PATH.

Run `nabe agent` and follow the guide for your kind of agent:
`nabe agent claude`, `nabe agent codex`, `nabe agent t3` or
`nabe agent other`. The guidance lives in the binary, so it matches the
installed version.
