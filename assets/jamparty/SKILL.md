# jamparty

The `jamparty` binary must be on your PATH.

Run `jamparty agent` and follow the guide for your kind of agent:
`jamparty agent claude`, `jamparty agent codex`, `jamparty agent t3` or
`jamparty agent other`. The guidance lives in the binary, so it matches the
installed version.
