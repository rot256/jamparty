# jamjam

The `jamjam` binary must be on your PATH.

Run `jamjam agent` and follow the guide for your kind of agent:
`jamjam agent claude`, `jamjam agent codex`, `jamjam agent t3` or
`jamjam agent other`. The guidance lives in the binary, so it matches the
installed version.
